## Local preview

```bash
git clone https://github.com/Rizwankhan0001/Rizwankhan0001.github.io.git
cd Rizwankhan0001.github.io
python3 -m http.server 8000
```

Then open http://localhost:8000.

The site uses local styles/scripts and some externally hosted web fonts. No compilation or package installation is required.
